# Samenvatting

Procenten zijn verhoudingsgetallen met honderd als vaste vergelijkingsbasis. $p\%$ betekent $p/100$. De belangrijkste vraag blijft: **wat is hier 100%?**

| Vraag | Berekening |
|---|---|
| Percentage van een geheel | Geheel maal $p/100$ |
| Deel als percentage | Deel gedeeld door geheel, maal 100 |
| Geheel terugvinden | Deel gedeeld door $p/100$ |
| Procentuele verandering | Verschil gedeeld door oude waarde, maal 100 |
| Nieuw na verandering | Oud maal groeifactor |
| Oud terugvinden | Nieuw gedeeld door niet-nulgroeifactor |

Bij opeenvolgende veranderingen vermenigvuldig je de factoren. Bij procentpunten trek je percentages af; bij relatieve verandering deel je het verschil ook door de oude waarde.

Controleer je taal naast je getal: '20% korting' is het weggenomen deel, '80% van de oude prijs' is het resterende deel. Een prijs met belasting vereist een andere terugrekening dan een belastingbedrag boven op de nettoprijs.
