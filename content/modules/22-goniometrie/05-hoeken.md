# Een hoek terugvinden

Ken je twee zijden, dan kun je eerst hun verhouding uitrekenen. De inverse functie vindt de bijbehorende hoek. Bij O/S = 0,5 is $\theta=\arcsin(0{,}5)=30^\circ$.

De toets sin⁻¹ op een rekenmachine betekent in deze context **arcsin**, niet de breuk 1/sin. Let ook hier op de gradenstand. In deze module zoek je een scherpe hoek; op dat interval is elke verhouding eenduidig terug te vertalen.

:::example Een helling
Een baan stijgt 2 meter bij 5 meter horizontale afstand. De hellingshoek is $\arctan(2/5)\approx21{,}80^\circ$. Een hellingspercentage van 40% betekent stijging/horizontale afstand = 0,4; het betekent niet een hoek van 40°.
:::

Bij een 3–4–5-driehoek is de hoek tegenover 3 ongeveer 36,87°. De andere scherpe hoek is 90° − 36,87° = 53,13°. Bereken die desgewenst ook met arcsin(4/5).
