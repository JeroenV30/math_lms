# Getallen voor letters invullen

Om $3x+5$ bij x = 4 uit te rekenen, vervang je elke x door 4: $3\times4+5=17$. De letter heeft op dat moment een gekozen waarde, maar de algemene expressie blijft ook voor andere waarden bruikbaar.

:::example Een negatief getal
Bij x = -2 is $x^2-3x=(-2)^2-3(-2)=4+6=10$. Zet negatieve ingevulde getallen tussen haakjes, vooral bij machten en producten.
:::

Bij twee letters vul je beide in: $2a+3b$ met a = 4 en b = -1 wordt $8-3=5$. Een waarde mag meerdere keren voorkomen; vervang elk voorkomen van dezelfde letter consequent.

## Niet elke waarde is toegestaan

Bij $5/x$ is x = 0 verboden, omdat je niet door nul kunt delen. Bij $\sqrt x$ gebruiken we hier alleen x ≥ 0. In een model kan een beperking ook uit de context komen: een aantal personen moet een niet-negatief geheel getal zijn.

:::tip Gebruik eenheden als controle
In een prijsregel met n exemplaren en € 3 per exemplaar geeft $3n$ euro's. Een vaste € 8 kun je daarbij optellen. Een aantal exemplaren en een bedrag rechtstreeks optellen zou verschillende grootheden mengen.
:::
