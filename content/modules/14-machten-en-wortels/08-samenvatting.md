# Samenvatting

Een macht herhaalt vermenigvuldiging. Een wortel maakt een kwadraat ongedaan als je de niet-negatieve hoofdwaarde kiest. Haakjes zijn onderdeel van de betekenis.

| Vorm | Regel |
|---|---|
| $a^m a^n$ | Exponenten optellen |
| $a^m/a^n$ | Exponenten aftrekken, $a\ne0$ |
| $(a^m)^n$ | Exponenten vermenigvuldigen |
| $a^0$ | 1 bij $a\ne0$ |
| $a^{-n}$ | $1/a^n$ bij $a\ne0$ |
| $\sqrt{a^2}$ | $|a|$ |

De regels voor producten zijn geen regels voor sommen. $\sqrt{a+b}$ is doorgaans niet $\sqrt a+\sqrt b$. $x^2=c$ kan twee reële oplossingen hebben, terwijl $\sqrt c$ één niet-negatieve hoofdwaarde is.

Gebruik wetenschappelijke notatie voor zeer grote of kleine getallen. Geef bij een wortel aan of je een exacte vorm of een afgeronde benadering zoekt.
